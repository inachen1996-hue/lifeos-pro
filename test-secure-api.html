⚙️ 环境配置

本地开发: 在 .env.local 文件中配置 API 密钥

Vercel 部署: 在 Vercel 项目设置中添加环境变量

其他平台: 根据平台要求配置环境变量

🔗 API 路由

GET /api/config - 获取可用的 API 服务列表

POST /api/config - 测试 API 连接或获取密钥

POST /api/deepseek - DeepSeek API 代理
