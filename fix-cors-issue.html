📚 技术说明

什么是 CORS？

跨域资源共享（CORS）是浏览器的安全机制，防止恶意网站访问其他域的资源。

为什么 DeepSeek 不支持？

DeepSeek API 主要设计为服务器端使用，没有设置允许浏览器跨域访问的 CORS 头。

Gemini 为什么可以？

Google Gemini API 专门为前端应用设计，支持浏览器直接调用。
