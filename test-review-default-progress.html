📊 复盘页面默认选中测试

✨ 新功能

现在进入复盘页面时，会自动选中"当前进度-今日"标签， 让用户可以立即查看今天的进度情况。

🧪 测试步骤

  1. 点击下方"打开主应用"按钮
  2. 点击底部导航栏的"复盘"按钮
  3. 观察是否自动选中"当前进度"标签
  4. 确认显示的是"今日"范围的数据

📋 复盘页面Tab模拟

📊

当前进度 - 今日

✅ 默认选中状态
显示今天的进度数据

🔧 实现方式

// 监听页面切换
useEffect(() => {
if (activePage === 'review') {
setReviewTab('progress');
setProgressScope('today');
}
}, [activePage]);

当用户切换到复盘页面时，自动设置为"当前进度-今日"

🎯 用户体验改进

  • • 直观性：进入复盘页面立即看到今日进度
  • • 效率：减少用户手动切换Tab的操作
  • • 一致性：每次进入都有相同的默认状态
  • • 实用性："今日进度"是最常查看的内容
