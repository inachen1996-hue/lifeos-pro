🔍 缓存验证测试工具

这个页面会帮助你验证浏览器是否使用了缓存的旧代码

⚠️ 重要提示
这个测试页面本身不包含特殊球体功能。
它会打开主应用并检查那里的代码版本。

📋 测试步骤

步骤 1: 打开主应用
点击上面的"打开主应用"按钮，或访问：
http://localhost:8000
步骤 2: 进入今日进度
在主应用中：
1. 点击底部导航的"复盘"
2. 选择"今日进度" Tab
3. 打开控制台（F12）
步骤 3: 检查日志
在控制台中查找这条日志：
✅ [Integrated] dropSpecialBall函数已暴露到全局
如果看到的是：
✅ dropSpecialBall函数已暴露到全局
说明使用了缓存的旧代码！需要清除缓存。
步骤 4: 测试功能
点击任意庆祝按钮（🍬 喝彩 / 🪙 鼓掌 / ⭐ 打鼓）

预期效果：
• 罐子顶部掉落彩色球体
• 球体受重力影响下落
• 球体触底后弹跳
• 手机震动（如果支持）
• 5秒后球体消失

🔧 清除缓存方法

方法 1: 强制刷新（最快）

Mac: Cmd + Shift + R Windows: Ctrl + Shift + R Linux: Ctrl + Shift + R

方法 2: 清空缓存并硬性重新加载（推荐）

  1. 在主应用页面按 F12 打开开发者工具
  2. 右键点击刷新按钮
  3. 选择"清空缓存并硬性重新加载"

方法 3: 清除站点数据（彻底）

  1. 按 F12 打开开发者工具
  2. 切换到 "Application" 标签
  3. 点击 "Storage" → "Clear site data"
  4. 点击 "Clear site data" 按钮
  5. 重新加载页面

方法 4: 使用隐身模式（验证）

Chrome: Cmd + Shift + N (Mac) / Ctrl + Shift + N (Windows) Firefox: Cmd + Shift + P (Mac) / Ctrl + Shift + P (Windows) Safari: Cmd + Shift + N (Mac)

在隐身窗口中访问 http://localhost:8000 测试

🧪 手动测试命令

在主应用的控制台中运行以下命令：

// 1. 检查函数是否存在 console.log('函数存在:', typeof window.dropSpecialBall); // 2. 检查函数版本（应该包含 [Integrated]） const funcStr = window.dropSpecialBall.toString(); console.log('包含[Integrated]标记:', funcStr.includes('[Integrated]')); console.log('函数代码片段:', funcStr.substring(0, 300)); // 3. 手动调用测试 window.dropSpecialBall('cheer'); // 掉落彩虹糖 window.dropSpecialBall('clap'); // 掉落金币 window.dropSpecialBall('drum'); // 掉落星星 // 4. 检查特殊球体 DOM 元素 setTimeout(() => { const balls = document.querySelectorAll('.special-ball'); console.log('特殊球体数量:', balls.length); balls.forEach((ball, i) => { console.log(`球体 ${i+1}:`, { 位置: ball.style.left + ', ' + ball.style.top, 大小: ball.style.width + ' x ' + ball.style.height, emoji: ball.textContent }); }); }, 1000);
