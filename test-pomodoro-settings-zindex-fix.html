🍅 番茄钟设置弹窗z-index修复测试

🐛 问题描述

番茄钟设置弹窗的保存按钮被底部导航栏遮挡，用户无法点击保存按钮。

问题原因

  • 番茄钟设置弹窗的 z-index 为 60
  • 底部导航栏的 z-index 为 100
  • 导航栏层级更高，遮挡了弹窗底部的保存按钮

✅ 解决方案

将番茄钟设置弹窗的 z-index 提高到 150，确保它显示在底部导航栏之上。

修改内容

// 修改前 <div className="fixed inset-0 z-[60] flex items-center justify-center bg-slate-900/20 backdrop-blur-sm p-4 animate-in"> // 修改后 <div className="fixed inset-0 z-[150] flex items-center justify-center bg-slate-900/20 backdrop-blur-sm p-4 animate-in">

Z-Index 层级表

组件 Z-Index 说明
普通内容 1-10 页面基础内容
悬浮按钮 40-50 创建按钮等
普通弹窗 60 一般模态框
Toast 提示 70 消息提示
底部导航栏 100 固定导航
重要弹窗 150 番茄钟设置等重要弹窗
特殊弹窗 200 日记等特殊情况

🧪 测试步骤

  1. 打开主应用 - 访问 index.html
  2. 进入设置页面 - 点击底部导航栏"设置"
  3. 打开番茄钟设置 - 点击"番茄钟设置"卡片
  4. 滚动到底部 - 查看保存按钮是否可见
  5. 点击保存按钮 - 验证按钮是否可以正常点击
  6. 测试不同屏幕 - 调整浏览器窗口大小测试

预期结果

  • ✅ 番茄钟设置弹窗完全显示在底部导航栏之上
  • ✅ 保存按钮完全可见且可点击
  • ✅ 取消按钮也完全可见且可点击
  • ✅ 弹窗可以正常滚动
  • ✅ 在各种屏幕尺寸下都正常工作
