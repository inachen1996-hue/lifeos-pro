🎯 问题分析

当前问题：
• 页面仍然无法上下滚动
• 触摸事件可能仍在阻止默认行为
• 需要更彻底的解决方案

💡 紧急修复策略

完全移除 preventDefault，使用纯 JavaScript 检测滑动：

// 紧急修复：完全移除 preventDefault const handleTouchStart = (e, timerId) => { const touch = e.targetTouches[0]; setTouchStart({ x: touch.clientX, y: touch.clientY, time: Date.now() }); setTouchEnd(null); // 不调用任何 preventDefault }; const handleTouchMove = (e, timerId) => { if (!touchStart) return; const touch = e.targetTouches[0]; // 只记录位置，不阻止任何默认行为 setTouchEnd({ x: touch.clientX, y: touch.clientY }); // 完全移除 preventDefault 调用 }; const handleTouchEnd = (timerId) => { if (!touchStart || !touchEnd) return; const distance = touchStart.x - touchEnd.x; const verticalDistance = Math.abs(touchStart.y - touchEnd.y); // 严格的水平滑动检测 const isLeftSwipe = distance > 80 && verticalDistance < 50; if (isLeftSwipe) { // 延迟执行，避免与滚动冲突 setTimeout(() => { setSwipedTimerId(timerId); }, 50); } setTouchStart(null); setTouchEnd(null); };

📋 修复代码

将以下代码替换到 index.html 中：

// 1. 替换 handleTouchStart const handleTouchStart = (e, timerId) => { const touch = e.targetTouches[0]; setTouchStart({ x: touch.clientX, y: touch.clientY, time: Date.now() }); setTouchEnd(null); }; // 2. 替换 handleTouchMove const handleTouchMove = (e, timerId) => { if (!touchStart) return; const touch = e.targetTouches[0]; setTouchEnd({ x: touch.clientX, y: touch.clientY }); }; // 3. 替换 handleTouchEnd const handleTouchEnd = (timerId) => { if (!touchStart || !touchEnd) return; const distance = touchStart.x - touchEnd.x; const verticalDistance = Math.abs(touchStart.y - touchEnd.y); // 更严格的滑动检测：需要更大的水平距离，更小的垂直偏移 const isLeftSwipe = distance > 80 && verticalDistance < 50; if (isLeftSwipe) { // 延迟执行，避免与滚动冲突 setTimeout(() => { setSwipedTimerId(timerId); }, 50); } setTouchStart(null); setTouchEnd(null); }; // 4. 同样修复计划页面的触摸事件 const handlePlanTouchStart = (e, index) => { if (!isMobile) return; const touch = e.touches[0]; setDraggedIndex(index); setTouchDragState({ isDragging: true, startY: touch.clientY, startX: touch.clientX, currentY: touch.clientY, currentX: touch.clientX }); }; const handlePlanTouchMove = (e, index) => { if (!isMobile || !touchDragState.isDragging) return; const touch = e.touches[0]; const currentY = touch.clientY; const currentX = touch.clientX; setTouchDragState(prev => ({ ...prev, currentY, currentX })); // 完全移除 preventDefault };

⚡ 替代方案：CSS 滚动强制

如果上述方法仍不工作，添加以下 CSS：

/* 强制启用滚动 */ html, body { overflow-y: scroll !important; -webkit-overflow-scrolling: touch !important; overscroll-behavior: auto !important; } /* 确保主容器可滚动 */ #root { overflow-y: auto !important; height: auto !important; min-height: 100vh !important; } /* 移除可能阻止滚动的样式 */ * { touch-action: auto !important; }
