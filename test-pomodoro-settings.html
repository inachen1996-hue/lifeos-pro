🍅 番茄钟设置功能测试

测试新增的番茄钟设置功能和AI计划生成集成

✅ 功能已实现：
番茄钟设置功能已成功添加到设置页面，支持自定义工作时长、休息时长和长休息周期

🎯 新增功能概览

1. 设置页面新增番茄钟设置卡片

  • 位置：设置页面，AI设置下方
  • 图标：番茄钟扁平图标
  • 状态显示：当前工作/休息时长配置
  • 交互：点击打开设置模态框

2. 番茄钟设置模态框

  • 工作时长：15-60分钟，默认25分钟
  • 短休息：3-15分钟，默认5分钟
  • 长休息：10-30分钟，默认15分钟
  • 长休息周期：2-8个番茄钟，默认4个
  • 预览效果：实时显示配置效果

3. AI计划生成集成

  • 提示词增强：将番茄钟设置传递给AI
  • 智能规划：AI根据用户设置安排工作和休息
  • 个性化：支持不同用户的专注习惯

🧪 测试步骤

步骤 1：访问番茄钟设置
  1. 打开应用，点击底部导航栏的"设置"
  2. 在设置页面找到"番茄钟设置"卡片
  3. 验证卡片显示当前配置（默认：25分钟工作 / 5分钟休息）
  4. 点击卡片打开设置模态框
步骤 2：配置番茄钟参数
  1. 调整工作时长滑块（测试15-60分钟范围）
  2. 调整短休息时长（测试3-15分钟范围）
  3. 调整长休息时长（测试10-30分钟范围）
  4. 调整长休息周期（测试2-8个番茄钟）
  5. 验证预览效果实时更新
  6. 点击"保存设置"
步骤 3：测试AI计划生成
  1. 切换到"计划"页面
  2. 填写今日状态和特殊事项
  3. 点击"生成今日计划"
  4. 验证生成的计划是否使用了自定义的番茄钟设置
  5. 检查工作块是否按照设定的时长安排
