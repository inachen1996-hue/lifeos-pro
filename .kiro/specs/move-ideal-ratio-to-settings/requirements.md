# 理想配比入口迁移需求文档

## 介绍

将"理想配比"功能从复盘页面移动到设置页面，以提供更合理的功能组织和用户体验。理想配比作为一个配置性功能，更适合放在设置页面中管理。

## 术语表

- **理想配比**: 用户设定的各分类（工作、学习、休息等）的理想时间分配，用于与实际时间进行对比分析
- **复盘页面**: 显示时间使用分析和回顾的页面，包含当前进度、复盘、习惯打卡等功能
- **设置页面**: 应用配置管理页面，包含AI设置、番茄钟设置等配置项
- **分类滑块**: 用于调整各分类时间配比的交互控件

## 需求

### 需求 1

**用户故事**: 作为用户，我希望在设置页面中管理理想配比，这样我可以将配置类功能集中管理。

#### 验收标准

1. WHEN 用户点击底部导航栏的"设置"按钮 THEN 系统应显示设置页面包含理想配比设置项
2. WHEN 用户点击理想配比设置项 THEN 系统应打开理想配比配置界面
3. WHEN 用户在理想配比界面调整分类时间 THEN 系统应实时保存配置并更新显示
4. WHEN 用户完成理想配比设置 THEN 系统应将新配置应用到复盘分析中
5. WHEN 用户访问复盘页面 THEN 系统应不再显示理想配比标签页

### 需求 2

**用户故事**: 作为用户，我希望理想配比设置界面保持原有的功能和视觉设计，这样我可以继续使用熟悉的操作方式。

#### 验收标准

1. WHEN 理想配比设置界面打开 THEN 系统应显示8个分类的滑块控件（工作、学习、休息、睡眠、生活、娱乐、健康、兴趣）
2. WHEN 用户拖动滑块 THEN 系统应实时更新对应分类的时间值和总时间显示
3. WHEN 总时间超过24小时 THEN 系统应显示警告提示
4. WHEN 用户调整配比 THEN 系统应保持原有的空气感马卡龙视觉风格
5. WHEN 设置完成 THEN 系统应提供明确的保存确认反馈

### 需求 3

**用户故事**: 作为用户，我希望复盘页面简化后更专注于数据分析，这样我可以更高效地查看时间使用情况。

#### 验收标准

1. WHEN 用户访问复盘页面 THEN 系统应只显示三个标签页：当前进度、复盘、习惯打卡
2. WHEN 用户查看复盘数据 THEN 系统应继续使用设置页面中配置的理想配比进行对比分析
3. WHEN 复盘页面布局调整 THEN 系统应保持原有的响应式设计和视觉效果
4. WHEN 用户切换复盘标签 THEN 系统应保持流畅的动画过渡效果
5. WHEN 理想配比数据更新 THEN 系统应在复盘页面中实时反映新的对比结果

### 需求 4

**用户故事**: 作为用户，我希望设置页面中的理想配比项有清晰的视觉标识，这样我可以快速找到和识别该功能。

#### 验收标准

1. WHEN 设置页面加载 THEN 系统应显示理想配比设置项使用目标图标和渐变背景
2. WHEN 理想配比设置项显示 THEN 系统应包含功能描述和当前配置状态
3. WHEN 用户悬停理想配比设置项 THEN 系统应显示悬停效果和视觉反馈
4. WHEN 设置项排列 THEN 系统应将理想配比放在合适的位置（建议在番茄钟设置之后）
5. WHEN 设置项样式 THEN 系统应与其他设置项保持一致的设计语言

### 需求 5

**用户故事**: 作为用户，我希望理想配比的数据迁移过程无缝进行，这样我不会丢失已有的配置。

#### 验收标准

1. WHEN 系统升级到新版本 THEN 系统应自动保留用户现有的理想配比设置
2. WHEN 理想配比功能迁移 THEN 系统应确保数据存储格式保持兼容
3. WHEN 用户首次访问新设置页面 THEN 系统应正确显示之前配置的理想配比值
4. WHEN 数据同步 THEN 系统应确保设置页面和复盘页面使用相同的配比数据
5. WHEN 配置更新 THEN 系统应在所有相关页面中实时反映变更
