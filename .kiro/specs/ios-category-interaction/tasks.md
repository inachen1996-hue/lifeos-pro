## 实现说明

### 关键技术点

1. **长按检测**: 使用 setTimeout 实现，需要同时支持鼠标和触摸事件
2. **抖动动画**: 使用 CSS @keyframes 定义，通过添加/移除类名控制
3. **拖动排序**: 使用原生事件实现（更好的移动端支持），而非 HTML5 Drag & Drop API
4. **状态管理**: 在 TimerPage 组件中集中管理编辑模式相关状态
5. **持久化**: 扩展 CategoryStorage 以支持排序和删除操作

### 实现顺序说明

1. 首先实现基础的编辑模式状态管理和动画
2. 然后实现长按检测，这是进入编辑模式的入口
3. 接着实现删除功能，因为它相对独立且重要
4. 最后实现拖动排序，这是最复杂的部分
5. 每个主要功能完成后编写对应的属性测试

### 测试策略

- 核心逻辑使用属性测试验证通用性
- 边界条件使用单元测试覆盖
- 完整流程使用集成测试验证
- 标记为 * 的测试任务为可选，但强烈建议实现
