✅ 更新完成

已按照要求更新侧边栏胶囊样式，让它们更像软糖，不再"胖硬"：

修改前 (胖硬)

工作

72×64px, 24px圆角, 边框描边

修改后 (软糖)

工作

70×56px, 20px圆角, 全填充

属性 修改前 修改后 改进效果
胶囊尺寸 72px × 64px 70px × 56px 更紧凑，不再"胖"
圆角 24px 20px 稍微方一点，更像软糖
垂直间距 16px 12px 更紧密的排列
文字大小 16px/14px (粗黑) 13px (600) 更精致的文字
选中态 渐变 + 边框 全填充色 去除硬边框，更柔软

🍭 软糖设计理念

  • 不再"胖" - 从72×64px缩小到70×56px，更苗条
  • 不再"硬" - 去除边框描边，改为全填充色
  • 软糖圆角 - 20px圆角，稍微方一点点，像软糖的形状
  • 精致文字 - 13px + 600字重，更加精致
  • 紧密排列 - 12px间距，胶囊之间更紧密

🧪 测试要点

  1. 尺寸检查 - 胶囊应该是70×56px，看起来更苗条
  2. 圆角验证 - 20px圆角，不是全圆角，稍微方一点
  3. 间距测试 - 胶囊之间12px间距，更紧密
  4. 文字样式 - 13px字号，600字重，更精致
  5. 选中态 - 无边框，全填充色，更柔软
  6. 软糖感觉 - 整体应该像软糖，不再胖硬

🔍 技术实现

胶囊容器：

// 间距调整
style={{ display: 'flex', flexDirection: 'column', gap: '12px' }}

// 胶囊尺寸
style={{
  width: '70px',
  height: '56px'
}}

// 圆角调整
className="rounded-[20px]"

文字样式：

// 新文字样式
style={{ fontSize: '13px', fontWeight: '600' }}

选中态优化：

// 去除边框，只保留填充色和阴影
boxShadow: '0 12px 32px -4px rgba(255, 181, 216, 0.4), inset 0 2px 8px rgba(255, 255, 255, 0.6)'
