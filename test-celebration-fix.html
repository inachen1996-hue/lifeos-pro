🔍 问题诊断
发现了两个独立的 specialBalls 状态：
  • ProgressTabContent 组件中的状态（外层）
  • AchievementJarContainer 组件中的状态（内层）
dropSpecialBall 函数修改的是外层状态，但渲染使用的是内层状态，导致球体不显示。

🛠️ 修复方案

将外层的 specialBalls 和 setSpecialBalls 作为 props 传递给 AchievementJarContainer 组件，让两个组件共享同一个状态。

修改 1: 传递 props

<AchievementJarContainer data={achievementJarData} categoryMap={categoryMap} timeRange={progressScope} specialBalls={specialBalls} setSpecialBalls={setSpecialBalls} onCelebrate={(type) => { playSound(type); generateDanmaku(); }} />
