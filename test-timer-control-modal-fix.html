🔧 TimerControlModal 修复测试

问题描述

错误信息:

TypeError: Cannot read properties of undefined (reading 'mode')
at TimerControlModal

问题原因:

在修复计时器数据保存逻辑时，错误地将 activeTimerSession 设置为只包含 completedSessions 的对象， 但 TimerControlModal 组件期望的是包含 timer 和 session 属性的对象。

修复方案

1. 修复 handleStopTimer 函数

计时器停止后，将 activeTimerSession 设置为 null，而不是只包含 completedSessions 的对象。

// 修复前: setActiveTimerSession(updatedSession);
// 修复后: setActiveTimerSession(null);

2. 保持数据完整性

completedSessions 数据仍然保存在 localStorage 中，Achievement Jar 可以从那里读取数据。

3. 数据流修复

✅ 计时器完成 → 保存到 completedSessions (localStorage)
✅ 清除 activeTimerSession 状态 → 避免 TimerControlModal 错误
✅ Achievement Jar 从 localStorage 读取数据 → 正常显示
