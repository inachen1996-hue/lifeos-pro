🎯 问题分析

当前问题：
• 移除 preventDefault 后页面无法滑动
• 需要区分水平滑动（功能）和垂直滚动（导航）

💡 智能解决方案

使用方向检测，只在水平滑动时阻止默认行为：

// 智能触摸事件处理 - 区分水平滑动和垂直滚动 const handleTouchStart = (e, timerId) => { const touch = e.targetTouches[0]; setTouchStart({ x: touch.clientX, y: touch.clientY, time: Date.now() }); setTouchEnd(null); }; const handleTouchMove = (e, timerId) => { if (!touchStart) return; const touch = e.targetTouches[0]; const deltaX = Math.abs(touch.clientX - touchStart.x); const deltaY = Math.abs(touch.clientY - touchStart.y); // 判断是否为水平滑动 const isHorizontalSwipe = deltaX > deltaY && deltaX > 10; // 只在水平滑动时阻止默认行为 if (isHorizontalSwipe && e.cancelable) { e.preventDefault(); } setTouchEnd({ x: touch.clientX, y: touch.clientY }); };
